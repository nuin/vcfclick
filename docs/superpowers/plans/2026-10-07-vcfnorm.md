# vcfnorm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in in-process multi-allelic splitting (`--split-multiallelic`, row-identical to `bcftools norm -m -`) and a `consequences` table decoded from VEP `CSQ` / SnpEff `ANN`, filled at ingest (`--decode-consequences`) or later (`vcfclick db consequences`).

**Architecture:** A new top-level `vcfnorm/` package that never imports `storage`, `cli`, `ingest`, chDB or DuckDB. `vcfnorm.split.SplitRecord` implements just enough of the cyvcf2 `Variant` API for the unchanged `ingest.vcf_rows.build_record_rows`. `vcfnorm.csq.decode` turns an Arrow table of variant keys plus raw annotation strings into consequence rows, using polars. The glue lives in `ingest/records.py` and `ingest/consequences.py`, plus the existing loaders, CLI and storage plumbing.

**Tech Stack:** Python ≥3.11, cyvcf2, numpy, pyarrow, polars (optional extra `csq`), click, chDB / DuckDB, pytest. bcftools 1.24 is the oracle.

**Spec:** `docs/superpowers/specs/2026-10-07-vcfnorm-design.md`

## Global Constraints

- `vcfnorm/` must not import `storage`, `cli`, `ingest`, `chdb` or `duckdb`. Allowed imports: cyvcf2, numpy, pyarrow, polars (only inside `vcfnorm/csq.py`, imported lazily), and the standard library.
- Default behaviour is unchanged. Without `--split-multiallelic`, a multi-allelic record is still rejected. The message must still contain `Multi-allelic` and `bcftools norm` (asserted by `tests/test_ingest_atomic.py:82-83` and `tests/test_ingest_batch.py:233`), and must now also name `--split-multiallelic`.
- Serial and parallel loaders must produce identical rows; both go through `ingest.records.decomposed`.
- `info_extra` is never modified by either feature.
- No left-alignment or trimming. Only plain `-m -` is mirrored (not `--multi-overlaps .`, `--keep-sum`, `--old-rec-tag`, `-m -snps|-indels`, or `-m +`).
- polars is an optional extra: `csq = ["polars>=1.20"]`. A missing polars must fail before any parsing, with the message `install the csq extra: uv tool install "vcfclick[csq]"`.
- `consequences` key: `ORDER BY (ingest_id, chrom, pos, ref, alt, source, entry)`. `source` is `'vep'` or `'snpeff'`; `entry` is a 0-based UInt16.
- Don't bump the version. Don't touch `packaging/bioconda/`.
- `uvx ruff@0.15.16 format --check .`, `uvx ruff@0.15.16 check .`, `uv run isort --check-only --diff .` and the full `uv run pytest tests/` must pass (CI also runs it with `VCFCLICK_BACKEND=duckdb`).
- Never open a chDB session inside the pytest process. Exercise storage through `tests.conftest.run_cli` or the `run_python` fixture.
- Commit messages: noun-first, present tense, no AI attribution. Work on branch `feature/vcfnorm`.

## Review Focus

1. **An annotated multi-allelic record whose split siblings straddle a Parquet batch boundary.** Every entry must still be decoded. Covered by a test in Task 8 that uses `batch_size=1` on the parallel loader.
2. **A malformed per-allele count** (`Number=A` INFO with the wrong number of values). The ingest must fail with an error naming `chrom:pos` and the field, before any database write, leaving earlier data under that `ingest_id` intact. Test in Task 3.
3. **A sites-only VCF** (no samples) with `--split-multiallelic`. It must split without touching genotype APIs. Test in Task 3.
4. **A gVCF `<NON_REF>` ALT** in a multi-allelic record. It must be split like any allele, not rejected as structural. Covered by the fixture and oracle in Tasks 2–3.
5. **A backfill over ingestions with no `CSQ`/`ANN`**, including a Parquet ingestion whose `vcf_path` is `parquet://…`. It must report zero rows and must not ask for `--csq-format`. Test in Task 9.

```python
"""Per-field declarations read from a VCF header."""

from __future__ import annotations

from dataclasses import dataclass, field


@dataclass(frozen=True)
class FieldNumbers:
    """`Number=` of every declared INFO and FORMAT field, as written in
    the header ("A", "R", "G", ".", "0", "1", "2", ...)."""

    info: dict[str, str] = field(default_factory=dict)
    fmt: dict[str, str] = field(default_factory=dict)


def _header_records(vcf):
    for h in vcf.header_iter():
        try:
            d = h.info(extra=True)
        except Exception:
            continue
        kind = str(d.get("HeaderType", "")).upper()
        fid = d.get("ID")
        if fid and kind in ("INFO", "FORMAT"):
            yield kind, fid, d


def field_numbers(vcf) -> FieldNumbers:
    info: dict[str, str] = {}
    fmt: dict[str, str] = {}
    for kind, fid, d in _header_records(vcf):
        number = str(d.get("Number", "."))
        (info if kind == "INFO" else fmt)[fid] = number
    return FieldNumbers(info, fmt)


def info_descriptions(vcf) -> dict[str, str]:
    """INFO ID → Description text, surrounding quotes removed."""
```

```python
"""Split a multi-allelic cyvcf2 record the way `bcftools norm -m -` does.

`SplitRecord` implements exactly the part of the cyvcf2 Variant API that
`ingest.vcf_rows.build_record_rows` reads, with values sliced out of the
parent record. Rules (verified against bcftools 1.24, see
docs/VCFNORM.md):

  Number=A  value k          Number=R  values 0, k
  Number=G  diploid (0,0),(0,k),(k,k); haploid 0, k
  other     copied unchanged (including CSQ / ANN strings)
  GT        allele k -> 1, any other ALT -> 0, missing and phase kept

A wholly missing per-sample value (`.`) stays missing; bcftools writes it
as `.,.` for Number=R and `.` otherwise, and the arrays below mirror what
cyvcf2 parses from that text.
"""

from __future__ import annotations

import re

import numpy as np

from vcfnorm.header import FieldNumbers

INT_MISSING = -2147483648
INT_END = -2147483647
FLOAT_MISSING_BITS = 0x7F800001
FLOAT_END_BITS = 0x7F800002

# Symbolic structural-variant ALTs and breakends are out of scope. The
# gVCF reference blocks `<*>` / `<NON_REF>` split like any other allele.
_SYMBOLIC_SV = re.compile(r"^<(?!\*>$|NON_REF>$).*>$")


class SplitError(ValueError):
    """A record cannot be split (bad value count, unsupported allele)."""


def value_indices(
    number: str, k: int, n_alleles: int, n_values: int
) -> list[int] | None:
    """Positions of allele `k`'s values among `n_values`, or None to copy.

    `n_alleles` counts REF plus every ALT. Number=G with `n_values ==
    n_alleles` is a haploid sample; otherwise diploid is required.
    """
    if number == "A":
        want, idx = n_alleles - 1, [k - 1]
    elif number == "R":
        want, idx = n_alleles, [0, k]
    elif number == "G":
        if n_values == n_alleles:
            want, idx = n_alleles, [0, k]
        else:
            base = k * (k + 1) // 2
            want, idx = n_alleles * (n_alleles + 1) // 2, [0, base, base + k]
    else:
        return None
    if n_values != want:
        raise SplitError(
            f"has {n_values} values, expected {want} for Number={number}"
        )
    return idx


def recode_gt(arr: np.ndarray, k: int) -> np.ndarray:
    """cyvcf2 `genotype.array()` for split allele `k`: allele k -> 1,
    other ALTs -> 0, missing (-1) / padding (-2) and the phase column kept."""
    alleles = arr[:, :-1]
    recoded = np.where(alleles == k, 1, np.where(alleles > 0, 0, alleles))
    return np.concatenate([recoded, arr[:, -1:]], axis=1).astype(arr.dtype)


def gt_types_from(arr: np.ndarray) -> np.ndarray:
    """cyvcf2's gt_types rule on a single-ALT allele array:
    nothing called -> UNKNOWN (2); no ALT -> HOM_REF (0); a missing
    allele next to an ALT (./1) -> HET (1); all ALT -> HOM_ALT (3);
    otherwise HET (1)."""
    alleles = arr[:, :-1]
    n_called = (alleles >= 0).sum(axis=1)
    n_alt = (alleles > 0).sum(axis=1)
    has_missing = (alleles == -1).any(axis=1)
    return np.select(
        [n_called == 0, n_alt == 0, has_missing, n_alt == n_called],
        [2, 0, 1, 3],
        default=1,
    ).astype(np.int32)


def _as_list(value) -> list:
    if isinstance(value, tuple):
        return list(value)
    if isinstance(value, str):
        return value.split(",")
    return [value]


def _split_info_value(value, number, k, n_alleles):
    if isinstance(value, bool) or value is None:
        return value
    vals = _as_list(value)
    idx = value_indices(number, k, n_alleles, len(vals))
    if idx is None:
        return value
    picked = [vals[i] for i in idx]
    if isinstance(value, str):
        return ",".join(picked)
    return picked[0] if len(picked) == 1 else tuple(picked)


def _split_numeric_format(arr, number, k, n_alleles):
    """Slice a numeric FORMAT array (n_samples, width) for allele `k`."""
    is_float = arr.dtype == np.float32
    bits = arr.view(np.int32) if is_float else arr.astype(np.int32, copy=False)
    missing = FLOAT_MISSING_BITS if is_float else INT_MISSING
    end = FLOAT_END_BITS if is_float else INT_END
    written: list[list[int] | None] = []
    for row in bits:
        vals = row[row != end]
        if vals.size == 0 or (vals.size == 1 and vals[0] == missing):
            written.append([missing, missing] if number == "R" else None)
            continue
        idx = value_indices(number, k, n_alleles, int(vals.size))
        written.append([int(vals[i]) for i in idx])
    width = max((len(w) for w in written if w is not None), default=1)
    out = np.full((len(written), width), end, dtype=np.int32)
    for i, w in enumerate(written):
        if w is None:
            out[i, 0] = missing
        else:
            out[i, : len(w)] = w
    return out.view(np.float32) if is_float else out.astype(arr.dtype)


def _split_string_format(arr, number, k, n_alleles):
    out = []
    for s in arr:
        s = str(s)
        if s in ("", "."):
            out.append(".,." if number == "R" else ".")
            continue
        parts = s.split(",")
        idx = value_indices(number, k, n_alleles, len(parts))
        out.append(",".join(parts[i] for i in idx))
    return np.array(out)


class _Parent:
    """One parent record, with its genotype and FORMAT arrays read once
    and shared by every SplitRecord made from it."""

    def __init__(self, variant, numbers: FieldNumbers):
        self.variant = variant
        self.numbers = numbers
        self.n_alleles = 1 + len(variant.ALT)
        self.site = f"{variant.CHROM}:{variant.POS}"
        self._format: dict[str, object] = {}
        self._gt = None
        self._gt_read = False

    def format(self, field):
        if field not in self._format:
            self._format[field] = self.variant.format(field)
        return self._format[field]

    def genotype_array(self):
        """Parent `genotype.array()`, or None when there is no GT."""
        if not self._gt_read:
            self._gt_read = True
            try:
                gt = self.variant.genotype
            except Exception:
                gt = None
            self._gt = None if gt is None else gt.array()
        return self._gt


class _Genotype:
    def __init__(self, arr: np.ndarray):
        self._arr = arr

    def array(self) -> np.ndarray:
        return self._arr


class SplitRecord:
    """One ALT of a multi-allelic record, shaped like a cyvcf2 Variant
    for `build_record_rows`. Anything else raises AttributeError."""

    __slots__ = ("_p", "_k", "_info", "_gt")

    def __init__(self, parent: _Parent, k: int):
        self._p = parent
        self._k = k
        self._info: dict | None = None
        self._gt: np.ndarray | None = None

    def _fail(self, kind: str, field: str, err: SplitError) -> SplitError:
        return SplitError(f"{self._p.site}: {kind}/{field} {err}")

    @property
    def allele_index(self) -> int:
        return self._k

    @property
    def CHROM(self):
        return self._p.variant.CHROM

    @property
    def POS(self):
        return self._p.variant.POS

    @property
    def ID(self):
        return self._p.variant.ID

    @property
    def REF(self):
        return self._p.variant.REF

    @property
    def ALT(self):
        return [self._p.variant.ALT[self._k - 1]]

    @property
    def QUAL(self):
        return self._p.variant.QUAL

    @property
    def FILTER(self):
        return self._p.variant.FILTER

    @property
    def INFO(self) -> dict:
        if self._info is None:
            out = {}
            for key, value in self._p.variant.INFO:
                number = self._p.numbers.info.get(key, ".")
                try:
                    out[key] = _split_info_value(value, number, self._k, self._p.n_alleles)
                except SplitError as e:
                    raise self._fail("INFO", key, e) from None
            self._info = out
        return self._info

    def format(self, field):
        arr = self._p.format(field)
        if arr is None:
            return None
        number = self._p.numbers.fmt.get(field, ".")
        if number not in ("A", "R", "G"):
            return arr
        try:
            if arr.dtype.kind in ("U", "S", "O"):
                return _split_string_format(arr, number, self._k, self._p.n_alleles)
            return _split_numeric_format(arr, number, self._k, self._p.n_alleles)
        except SplitError as e:
            raise self._fail("FORMAT", field, e) from None

    def _gt_array(self):
        if self._gt is None:
            parent = self._p.genotype_array()
            if parent is not None:
                self._gt = recode_gt(parent, self._k)
        return self._gt

    @property
    def genotype(self):
        arr = self._gt_array()
        if arr is None:
            # Same contract as cyvcf2: no GT -> genotype unavailable.
            return self._p.variant.genotype
        return _Genotype(arr)

    @property
    def gt_types(self):
        arr = self._gt_array()
        if arr is None:
            return self._p.variant.gt_types
        return gt_types_from(arr)

    @property
    def gt_phases(self):
        return self._p.variant.gt_phases


def split_record(variant, numbers: FieldNumbers) -> list[SplitRecord]:
    """One SplitRecord per ALT, in ALT order."""
    for alt in variant.ALT:
        if _SYMBOLIC_SV.match(alt) or "[" in alt or "]" in alt:
            raise SplitError(
                f"{variant.CHROM}:{variant.POS}: symbolic structural-variant "
                f"allele {alt!r} cannot be split"
            )
    parent = _Parent(variant, numbers)
    return [SplitRecord(parent, k) for k in range(1, len(variant.ALT) + 1)]
```

```markdown
# Normalisation and consequences (`vcfnorm`)

## Splitting multi-allelic records

vcfclick stores one ALT per `variants` row. A multi-allelic record is
rejected unless you either split it beforehand:

    bcftools norm -m - in.vcf.gz | bgzip > split.vcf.gz

or pass `--split-multiallelic` to `db ingest` / `db ingest-batch`, which
splits in process. The rows are identical to the bcftools route (this is
tested against bcftools 1.24 output):

| field | split record for ALT k |
|---|---|
| CHROM, POS, ID, REF, QUAL, FILTER | copied |
| `Number=A` | value k |
| `Number=R` | values 0 and k |
| `Number=G` | diploid (0,0), (0,k), (k,k); haploid 0, k |
| other INFO/FORMAT (incl. `CSQ`, `ANN`) | copied unchanged |
| GT | allele k → 1, any other ALT → 0 (`1/2` → `1/0` and `0/1`; `./2` → `./0` and `./1`) |

This is bcftools' default `--multi-overlaps 0`. Called counts
(`n_called`, `an_called`, `ac_called`) and `missing_genotypes` are then
computed per split row, so they are exact per allele.

Not done: left-alignment and allele trimming (`ATG>C` stays `ATG>C`),
which need a reference FASTA — run `bcftools norm -f ref.fa` for that.
Symbolic structural-variant alleles (`<DEL>`, breakends) and `Number=G`
fields above ploidy 2 are rejected; `<*>` / `<NON_REF>` split normally.
```

```sql
-- Decoded VEP CSQ / SnpEff ANN annotations, one row per annotation entry
-- matched to a variant ALT. Joins to `variants` on
-- (ingest_id, chrom, pos, ref, alt). Filled by `db ingest
-- --decode-consequences` or `db consequences`; the raw string stays in
-- variants.info_extra['CSQ'|'ANN'].
--
-- Keyed by (source, entry) rather than transcript: intergenic entries
-- have no feature id, and VEP can repeat a feature, which a
-- ReplacingMergeTree key on transcript would collapse.

CREATE TABLE consequences (
    ingest_id      LowCardinality(String),

    chrom          LowCardinality(String),
    pos            UInt32,
    ref            String,
    alt            String,

    source         LowCardinality(String),        -- 'vep' | 'snpeff'
    entry          UInt16,                        -- 0-based position in the raw string
    allele         String,                        -- annotation's own Allele, raw
    consequence    Array(String),                 -- SO terms, split on '&'
    impact         LowCardinality(Nullable(String)),
    gene_symbol    Nullable(String),
    gene_id        Nullable(String),
    feature_type   LowCardinality(Nullable(String)),
    transcript_id  Nullable(String),
    biotype        LowCardinality(Nullable(String)),
    hgvsc          Nullable(String),
    hgvsp          Nullable(String),
    exon           Nullable(String),              -- "3/12"
    intron         Nullable(String),
    canonical      Nullable(UInt8),               -- VEP CANONICAL=YES -> 1; NULL for SnpEff
    mane_select    Nullable(String),
    csq_extra      Map(String, String),           -- every other non-empty subfield

    ingested_at    DateTime DEFAULT now()
)
ENGINE = ReplacingMergeTree(ingested_at)
ORDER BY (ingest_id, chrom, pos, ref, alt, source, entry);
```

```python
"""How annotation tools spell an ALT allele, so entries can be matched
back to the variant they describe."""

from __future__ import annotations


def vep_group_alleles(ref: str, alts: list[str]) -> dict[str, str]:
    """VEP's default `Allele` for each ALT of one original record: when
    REF and every ALT share their first base, that base is dropped from
    all of them (empty -> '-'); otherwise alleles are left as written."""
    alleles = [ref, *alts]
    first = {a[:1] for a in alleles}
    if len(first) == 1 and all(len(a) > 0 for a in alleles):
        return {alt: alt[1:] or "-" for alt in alts}
    return {alt: alt for alt in alts}


def minimal_allele(ref: str, alt: str) -> str:
    """VEP `--minimal`: trim the shared prefix, then the shared suffix,
    from this REF/ALT pair alone (empty -> '-')."""
    i = 0
    while i < min(len(ref), len(alt)) and ref[i] == alt[i]:
        i += 1
    r, a = ref[i:], alt[i:]
    j = 0
    while j < min(len(r), len(a)) and r[-1 - j] == a[-1 - j]:
        j += 1
    if j:
        a = a[: len(a) - j]
    return a or "-"


def candidates(source: str, ref: str, alts: list[str]) -> list[tuple[str, str, int]]:
    """(alt, representation, priority) pairs to match an entry's Allele
    against; the lowest priority that matches wins."""
    if source == "snpeff":
        return [(alt, alt, 0) for alt in alts]
    group = vep_group_alleles(ref, alts)
    out = []
    for alt in alts:
        out.append((alt, group[alt], 0))
        out.append((alt, minimal_allele(ref, alt), 1))
        out.append((alt, alt, 2))
    return out
```

```python
import re  # noqa: E402  (keep with the stdlib imports at the top when tidying)
from dataclasses import dataclass  # noqa: E402
from urllib.parse import unquote  # noqa: E402

from vcfnorm.alleles import candidates  # noqa: E402

SNPEFF_FIELDS: tuple[str, ...] = (

# Header subfield -> typed column. Rank (SnpEff) is routed to exon or
# intron per entry; CANONICAL becomes 0/1.
_TYPED = {
    "vep": {
        "Allele": "allele", "Consequence": "consequence", "IMPACT": "impact",
        "SYMBOL": "gene_symbol", "Gene": "gene_id", "Feature_type": "feature_type",
        "Feature": "transcript_id", "BIOTYPE": "biotype", "HGVSc": "hgvsc",
        "HGVSp": "hgvsp", "EXON": "exon", "INTRON": "intron",

    },
    "snpeff": {

        "Annotation_Impact": "impact", "Gene_Name": "gene_symbol",
        "Gene_ID": "gene_id", "Feature_Type": "feature_type",
        "Feature_ID": "transcript_id", "Transcript_BioType": "biotype",
        "HGVS.c": "hgvsc", "HGVS.p": "hgvsp", "Rank": "rank",
    },
}
_STRING_COLUMNS = (
    "impact", "gene_symbol", "gene_id", "feature_type", "transcript_id",
    "biotype", "hgvsc", "hgvsp", "exon", "intron", "mane_select",

@dataclass(frozen=True)
class AnnotationFormat:
    tag: str  # INFO key: "CSQ" or "ANN"
    source: str  # "vep" or "snpeff"
    fields: tuple[str, ...]


@dataclass(frozen=True)
class DecodeResult:
    table: pa.Table
    decoded: int
    dropped: int


class MissingPolarsError(RuntimeError):
    pass


def require_polars():
    try:
        import polars
    except ImportError:
        raise MissingPolarsError(
            'consequence decoding needs polars; install the csq extra: '
            'uv tool install "vcfclick[csq]"'
        ) from None
    if polars is None:  # sys.modules entry blocked
        raise MissingPolarsError(
            'consequence decoding needs polars; install the csq extra: '
            'uv tool install "vcfclick[csq]"'
        )
    return polars


def vep_fields(description: str) -> tuple[str, ...]:
    m = re.search(r"Format:\s*([^\"']+)", description)
    if not m:
        raise ValueError(
            "CSQ header description has no 'Format: Allele|...' field list"
        )
    return tuple(f.strip() for f in m.group(1).strip().split("|"))


def annotation_formats(
    descriptions: dict[str, str], csq_format: str | None = None
) -> list[AnnotationFormat]:
    out = []
    if csq_format:
        out.append(AnnotationFormat("CSQ", "vep", tuple(
            f.strip() for f in csq_format.split("|"))))
    elif "CSQ" in descriptions:
        out.append(AnnotationFormat("CSQ", "vep", vep_fields(descriptions["CSQ"])))
    if "ANN" in descriptions:
        out.append(AnnotationFormat("ANN", "snpeff", SNPEFF_FIELDS))
    return out


def _empty(schema: pa.Schema) -> pa.Table:
    return pa.Table.from_pylist([], schema=schema)


def _to_map(column) -> pa.Array:
    """polars list<struct<key, value>> (as Arrow) -> map<string, string>."""
    arr = column.combine_chunks() if hasattr(column, "combine_chunks") else column
    value_type = arr.type.value_type
    arr = arr.cast(pa.list_(value_type))
    flat = arr.flatten()
    return pa.MapArray.from_arrays(
        arr.offsets,
        flat.field("key").cast(pa.string()),
        flat.field("value").cast(pa.string()),
    )


def decode(variants: pa.Table, fmt: AnnotationFormat, schema: pa.Schema) -> DecodeResult:
    """Decode one annotation tag for a batch of variants.

    `variants`: ingest_id, chrom, pos, ref, alt, raw (the tag's string,
    NULL when absent). Records sharing (ingest_id, chrom, pos, ref) and an
    identical raw string are siblings split from one original record;
    their ALTs form the allele group entries are matched against.
    """
    pl = require_polars()
    keys = ["ingest_id", "chrom", "pos", "ref"]
    df = pl.from_arrow(variants).filter(
        pl.col("raw").is_not_null() & ~pl.col("raw").is_in(["", "."])
    )
    if df.height == 0:
        return DecodeResult(_empty(schema), 0, 0)

    groups = (
        df.group_by([*keys, "raw"], maintain_order=True)
        .agg(pl.col("alt"))
        .with_row_index("group")
    )
    cand = {"group": [], "cand_alt": [], "match": [], "priority": []}
    for g, ref, alts in groups.select("group", "ref", "alt").iter_rows():
        for alt, rep, prio in candidates(fmt.source, ref, list(alts)):
            cand["group"].append(g)
            cand["cand_alt"].append(alt)
            cand["match"].append(rep)
            cand["priority"].append(prio)
    cands = pl.DataFrame(cand, schema={
        "group": pl.UInt32, "cand_alt": pl.String, "match": pl.String,
        "priority": pl.UInt8,
    })

    n_fields = len(fmt.fields)
    entries = (
        groups.select("group", *keys, "raw")
        .with_columns(pl.col("raw").str.split(",").alias("text"))
        .with_columns(
            pl.int_ranges(0, pl.col("text").list.len(), dtype=pl.UInt16).alias("entry")
        )
        .explode(["text", "entry"])
        .with_columns(pl.col("text").str.split("|").alias("parts"))
    )
    total = entries.height
    n_parts = pl.col("parts").list.len()
    well_formed = n_parts >= n_fields if fmt.source == "snpeff" else n_parts == n_fields
    allele_at = fmt.fields.index("Allele")
    entries = entries.filter(well_formed).with_columns(
        pl.col("parts").list.get(allele_at).alias("allele")
    )

    m = entries.join(
        cands, left_on=["group", "allele"], right_on=["group", "match"], how="inner"
    )
    m = m.filter(pl.col("priority") == pl.col("priority").min().over(["group", "entry"]))
    m = m.filter(pl.col("cand_alt").n_unique().over(["group", "entry"]) == 1)
    m = m.unique(["group", "entry"], keep="first", maintain_order=True)
    dropped = total - m.height
    if m.height == 0:
        return DecodeResult(_empty(schema), 0, dropped)

    typed = _TYPED[fmt.source]

    def value(i: int):
        v = pl.col("parts").list.get(i, null_on_oob=True)
        v = pl.when(v == "").then(None).otherwise(v)
        if fmt.source == "vep":
            v = pl.when(v.str.contains("%", literal=True)).then(
                v.map_elements(unquote, return_dtype=pl.String)
            ).otherwise(v)
        return v

    cols = {}
    extras = []
    for i, name in enumerate(fmt.fields):
        target = typed.get(name)
        if name == "MANE" and "MANE_SELECT" not in fmt.fields:
            target = "mane_select"
        if target is None or target in cols:
            extras.append(pl.struct(pl.lit(name).alias("key"), value(i).alias("value")))
        else:
            cols[target] = value(i)
    if fmt.source == "snpeff":
        max_parts = m.select(n_parts.max()).item()
        for i in range(len(SNPEFF_FIELDS), max_parts):
            extras.append(pl.struct(
                pl.lit(f"field_{i + 1}").alias("key"), value(i).alias("value")
            ))

    consequence = (
        pl.col("_consequence").fill_null("").str.split("&")
        .list.eval(pl.element().filter(pl.element() != ""))
    )
    out = m.with_columns(
        **{f"_{k}": v for k, v in cols.items()},
        _extra=pl.concat_list(extras) if extras else pl.lit(None),
    ).with_columns(_consequence_list=consequence)

    if fmt.source == "snpeff":
        is_intron = pl.col("_consequence_list").list.contains("intron_variant")
        exon = pl.when(~is_intron).then(pl.col("_rank"))
        intron = pl.when(is_intron).then(pl.col("_rank"))
        canonical = pl.lit(None, dtype=pl.UInt8)
    else:
        exon = pl.col("_exon") if "exon" in cols else pl.lit(None, dtype=pl.String)
        intron = pl.col("_intron") if "intron" in cols else pl.lit(None, dtype=pl.String)
        canonical = (
            (pl.col("_canonical") == "YES").fill_null(False).cast(pl.UInt8)
            if "canonical" in cols else pl.lit(None, dtype=pl.UInt8)
        )

    def col_or_null(name: str):
        return pl.col(f"_{name}") if name in cols else pl.lit(None, dtype=pl.String)

    if extras:
        extra = pl.col("_extra").list.eval(
            pl.element().filter(pl.element().struct.field("value").is_not_null())
        )
    else:
        extra = pl.lit([], dtype=pl.List(pl.Struct({"key": pl.String, "value": pl.String})))

    result = out.select(
        "ingest_id", "chrom", "pos", "ref",
        pl.col("cand_alt").alias("alt"),
        pl.lit(fmt.source).alias("source"),
        "entry",
        pl.col("allele"),
        pl.col("_consequence_list").alias("consequence"),
        *[col_or_null(c).alias(c) for c in _STRING_COLUMNS if c not in ("exon", "intron")],
        exon.alias("exon"),
        intron.alias("intron"),
        canonical.alias("canonical"),
        extra.alias("csq_extra"),
    )
    arrow = result.to_arrow()
    columns = []
    for field in schema:
        if field.name == "csq_extra":
            columns.append(_to_map(arrow.column("csq_extra")))
        else:
            columns.append(arrow.column(field.name).cast(field.type))
    return DecodeResult(pa.Table.from_arrays(columns, schema=schema), m.height, dropped)
```

```python
"""Consequence decoding glue: stage decoded rows at ingest, and backfill
existing ingestions from variants.info_extra."""

from __future__ import annotations

from pathlib import Path

import pyarrow as pa
import pyarrow.parquet as pq

from ingest._arrow import CONSEQUENCES_ARROW_SCHEMA, VARIANTS_COLUMNS
from vcfnorm.csq import AnnotationFormat, DecodeResult, annotation_formats, decode
from vcfnorm.header import info_descriptions

_KEY_IDX = [VARIANTS_COLUMNS.index(c) for c in ("ingest_id", "chrom", "pos", "ref", "alt")]
_EXTRA_IDX = VARIANTS_COLUMNS.index("info_extra")


def formats_for_vcf(vcf, csq_format: str | None = None) -> list[AnnotationFormat]:
    return annotation_formats(info_descriptions(vcf), csq_format)


def _decode_table(table: pa.Table, formats) -> DecodeResult:
    parts, decoded, dropped = [], 0, 0
    for fmt in formats:
        res = decode(
            table.append_column("raw", table.column(f"raw_{fmt.tag}")).select(
                ["ingest_id", "chrom", "pos", "ref", "alt", "raw"]
            ),
            fmt,
            CONSEQUENCES_ARROW_SCHEMA,
        )
        parts.append(res.table)
        decoded += res.decoded
        dropped += res.dropped
    if not parts:
        return DecodeResult(CONSEQUENCES_ARROW_SCHEMA.empty_table(), 0, 0)
    return DecodeResult(pa.concat_tables(parts), decoded, dropped)


def decode_rows(variant_rows: list[list], formats) -> DecodeResult:
    """Decode the CSQ/ANN of variant rows (VARIANTS_COLUMNS order)."""
    names = ("ingest_id", "chrom", "pos", "ref", "alt")
    cols = {
        name: pa.array(
            [r[i] for r in variant_rows],
            pa.uint32() if name == "pos" else pa.string(),
        )
        for name, i in zip(names, _KEY_IDX)
    }
    for fmt in formats:
        # Typed explicitly: an all-NULL batch must still be a string column.
        cols[f"raw_{fmt.tag}"] = pa.array(
            [r[_EXTRA_IDX].get(fmt.tag) for r in variant_rows], pa.string()
        )
    return _decode_table(pa.table(cols), formats)


def stage_consequences(variant_rows: list[list], formats, path: Path) -> DecodeResult:
    res = decode_rows(variant_rows, formats)
    pq.write_table(res.table, path)
    return res
```

```python
import logging  # noqa: E402  (move to the top imports when tidying)
import tempfile  # noqa: E402
from dataclasses import dataclass  # noqa: E402

log = logging.getLogger(__name__)


@dataclass(frozen=True)
class BackfillReport:
    ingest_id: str
    variants: int
    decoded: int
    dropped: int


def _header_formats(vcf_path: str, csq_format: str | None):
    """Formats from the source VCF's header, or None if unreadable."""
    if csq_format:
        return annotation_formats({"CSQ": "", "ANN": ""}, csq_format)
    if vcf_path.startswith("parquet://") or not Path(vcf_path).exists():
        return None
    from cyvcf2 import VCF

    return formats_for_vcf(VCF(vcf_path))


def _backfill_one(ingest_id: str, vcf_path: str, csq_format: str | None) -> BackfillReport:
    from ingest.vcf_load import _import_parquet
    from storage import (
        delete_where_sql, get_session, ingest_id_lock, map_value_expr,
        query_arrow, sql_quote_str,
    )

    q = sql_quote_str(ingest_id)
    # chDB hands back LowCardinality columns as Arrow dictionaries; the
    # cast below normalises both backends to plain types.
    table = query_arrow(
        "SELECT ingest_id, chrom, pos, ref, alt, "
        f"{map_value_expr('info_extra', 'CSQ')} AS raw_CSQ, "
        f"{map_value_expr('info_extra', 'ANN')} AS raw_ANN "
        f"FROM variants WHERE ingest_id = {q}"
    )
    has = {
        tag: table.num_rows > 0
        and table.column(f"raw_{tag}").null_count < table.num_rows
        for tag in ("CSQ", "ANN")
    }
    formats: list[AnnotationFormat] = []
    if has["CSQ"] or has["ANN"]:
        found = list(_header_formats(vcf_path, csq_format) or [])
        tags = {f.tag for f in found}
        if has["CSQ"] and "CSQ" not in tags:
            raise ValueError(
                f"ingestion {ingest_id!r}: CSQ field order unknown "
                f"({vcf_path} is not readable); pass --csq-format 'Allele|...'"
            )
        if has["ANN"] and "ANN" not in tags:
            # SnpEff's layout is fixed, so the header is not needed.
            found.append(AnnotationFormat("ANN", "snpeff", SNPEFF_FIELDS))
        formats = [f for f in found if has[f.tag]]

    table = table.cast(pa.schema([
        pa.field("ingest_id", pa.string()), pa.field("chrom", pa.string()),
        pa.field("pos", pa.uint32()), pa.field("ref", pa.string()),
        pa.field("alt", pa.string()), pa.field("raw_CSQ", pa.string()),
        pa.field("raw_ANN", pa.string()),
    ]))
    result = _decode_table(table, formats)

    with ingest_id_lock(ingest_id), tempfile.TemporaryDirectory() as tmp:
        path = Path(tmp) / "consequences.parquet"
        pq.write_table(result.table, path)
        get_session().query(delete_where_sql("consequences", f"ingest_id = {q}"))
        if result.table.num_rows:
            _import_parquet("consequences", path)
    return BackfillReport(ingest_id, table.num_rows, result.decoded, result.dropped)


def backfill_consequences(
    ingest_id: str | None = None, csq_format: str | None = None
) -> list[BackfillReport]:
    """Decode info_extra['CSQ'|'ANN'] of existing ingestions into
    `consequences`, replacing that ingestion's rows (idempotent)."""
    from storage import query_arrow, upgrade_schema
    from vcfnorm.csq import require_polars

    require_polars()
    upgrade_schema()
    rows = query_arrow(
        "SELECT ingest_id, vcf_path FROM ingestions ORDER BY ingest_id"
    ).to_pylist()
    if ingest_id is not None:
        rows = [r for r in rows if r["ingest_id"] == ingest_id]
        if not rows:
            raise ValueError(f"no ingestion {ingest_id!r} in this database")
    return [_backfill_one(r["ingest_id"], r["vcf_path"], csq_format) for r in rows]
```

```markdown
## Consequences

`--decode-consequences` (at ingest) or `vcfclick db consequences <db>`
(afterwards) decodes VEP `CSQ` and SnpEff `ANN` into the `consequences`
table (see SCHEMA.md). Needs the `csq` extra:

    uv tool install "vcfclick[csq]"

VEP's field order comes from the `Format:` list in the CSQ header. The
backfill reads it from the original VCF (`ingestions.vcf_path`); if that
file is gone, pass it with `--csq-format 'Allele|Consequence|...'`.

### Matching entries to ALTs

A split record carries the original record's whole annotation string, so
each entry is matched to the ALT it describes, within the group of
records at the same site that share that string:

1. VEP's default allele: when REF and every ALT share their first base,
   that base is dropped (`AT>A` is `-`, `C>CTT` is `TT`); otherwise the
   allele is as written (`ATG>A,ATGTG,C` stays `A`, `ATGTG`, `C`).
2. VEP `--minimal` form (shared prefix and suffix trimmed per pair).
3. The literal ALT (SnpEff).

Entries matching no ALT (for example an allele filtered out before
ingest) are dropped and counted; `db consequences` prints
`decoded=` / `dropped=` per ingestion. `ALLELE_NUM` is kept in
`csq_extra` but not used, so ingest-time and backfill results are
identical.
```
